## Principle
Build the **same look and feel** we would put on a public product. Privacy is an access/IP gate, not an excuse for “internal tool” UI. When productize unlocks, we should not need a redesign — only packaging, plans, and public IA.

## Feel target (one line)
**Private Messari × Token Terminal × Glassnode weather** — dark, sparse, institutional, cite-first. Artemis composure; DefiLlama density patterns only where tables need them.

## Comp map
| Comp | Steal | Never steal |
|------|-------|-------------|
| Artemis | Calm chrome, comparable metrics, professional restraint | Chain-compare as hero |
| Token Terminal | Equity-style fundamentals framing, clean charts | Metric soup |
| Messari | Research + data hybrid, profiles, events | Newsletter chrome as product |
| Glassnode Studio | Regime weather strip, serious dark studio | BTC monoculture |
| DefiLlama | Fast dense tables | Rainbow TVL explorer vibe |
| Koyfin | Portfolio + research split panes | Retail chart carnival |
| Tegus | Transcript → insight → name provenance | Call-library marketplace UX |

## Product surfaces (same in private + public)
1. **Home / Command** — regime weather, GATE, falsifiers, Show vs Act counts  
2. **Signal** — Sense pack, theme OW/N/UW as *stances*, cited hits  
3. **Sources** — citation drawer / provenance  
4. **Conviction Show** — top-100 line-signed desk, write-ups, never Act  
5. **Book / Act** — scarce Vera-signed weights only  
6. **Risk** — ceilings, attestations, vetoes  

Public product later may add marketing shell + auth/plans; **core desk chrome stays identical**.

## Hard UI laws
- Show ≠ Act visually (banner, density, stamp language)
- Sense OW/N/UW never look like portfolio ranks
- Every investable claim opens Sources
- Dark institutional palette, minimal accents, typography-first
- No meme crypto aesthetics, no “internal admin” greys-on-greys without craft
- Empty states are intentional and premium, not broken
